# Problem 2

Create the specified data frame with numeric, logical, character, and
factor vectors. I first set a randomization seed so the numeric vector
generated with random sampling produced the same result.

``` r
set.seed(7)

data_frame <- tibble(
  numeric_vector = rnorm(n = 10, mean = 0, sd = 1),
  logical_vector = numeric_vector > 0, 
  character_vector = c("a", "b", "c", "d", "e", "f", "g", "h", "i", "j"),
  factor_vector = factor(c("dog", "dog", "dog", "dog", "cat", "cat", "cat", "horse", "horse", "horse"))
)
```

The mean of the numeric vector:

``` r
data_frame |>

```

The mean of the logical vector:

The mean of the factor vector:

``` r
data_frame |>

```

Thus, the mean is calculated for the numeric and logical vectors, but
not the character and factor vectors.

Next, what if we convert the logical, character, and factor vectors to
numeric vectors?

``` r
data_frame_type_convert <- data_frame |> 
      mutate(
        logical_vector = as.numeric(logical_vector),
        character_vector = as.numeric(character_vector),
        factor_vector = as.numeric(factor_vector)
        )
```

The logical vector is converted to 1’s (TRUE) and 0’s (FALSE),
reflecting the underlying boolean values of the logical vector. The
character vector is converted entirely to missing values because the
character vector only contains alphabetical text values which cannot be
converted to numeric values. The factor vector is converted to 1’s
(cat), 2’s (dog), and 3’s (horse), reflecting the underlying
lexicographic integer ordering of the three categories when the factor
vector was first created.

These conversions help clarify why the mean was calculated for the
logical vector, as the underlying data for the logical vector were
boolean values which are appropriate inputs to the mean function. These
conversions also clarify why the mean was not calculated for the
character vector, as the underlying data were text which is not an
appropriate input to the mean function. Finally, the conversions
demonstrate the complexity of factor vectors. Factor vectors comprise
categorical text, which is not an appropriate input to the mean
function; however, these factor vectors also have an underlying integer
indexing each unique element within the vector, such that conversion to
a numeric vector is possible and outputs a numeric vector comprised of
the integer orderings.
